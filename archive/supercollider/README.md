# SuperCollider archive

Archived on 2026-11-11 following the composer's decision to keep the Apomixis repository and use SuperCollider as historical reference. Files were moved without changing their contents.

This directory preserves the setup, compositional core, nine numbered pieces, legacy sketches, generated exports, performance instructions, roadmap and TeX template. The former relative layout is preserved inside this directory. Historical instructions may contain stale paths and describe superseded status.

Do not execute this material against connected hardware. MIDI channels and stop/controller assignments are provisional. The declared attack-rate value is not an enforced safety limit. No SuperCollider runtime or hardware test was performed for this archival change.

The active project contract is [../../AGENTS.md](../../AGENTS.md). Port musical behavior through tested adapters and deterministic fixtures; do not make the browser applications depend on launching SuperCollider.
