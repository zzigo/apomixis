# LAB 14 / IMPRO — states for the IMPRO pod. Candidate lab score.
# The organist plays Manual I (channel 1). The pod re-sends each note to other divisions:
#   tap DIVISION SEMITONES DELAY-MS   one echo: where, at which interval, how late
#   rep N every MS stretch F           repeat the whole chain N times, each pass later and slower
#   tail F                             echo length = held time × F (long tails → counterpoint)
#   decay P                            later passes thin out with probability P per pass
# This score only changes state and registration cue with the form; it plays no notes itself
# (apart from one pedal drone). IMPRO pod: ARM, SCORE checked, MIDI IN = the console.
# A tap can never target the source manual. The same lines work as states 1–9 in the pod.
id apomixis.lab.impro
version 0.1.0-lab.1
title "IMPRO"
number lab14
duration 300
seed 3141
audition-transpose 0

voice $SO = so range 36 84
voice $RE = re range 36 84
voice $PO = po range 36 84
voice $GO = go range 36 84
voice $PE = pe range 24 55
fertility $SO 0 end
fertility $RE 0 end
fertility $PO 0 end
fertility $GO 0 end
fertility $PE 0 end
harmonicity 0 "P8" "the player decides"
harmonicity 300 "P8" ""

section A "Canon at the unison" for 50 bpm 60
native off
pgm I.bourdon8 II.bourdon8 III.corDeNuit8 73
laser off
impro src I tap II 0 400 tap III 0 800 tap IV 0 1200 tail 1
bio "timbre canon · the same pitch on four flutes, 400 ms apart"
end
