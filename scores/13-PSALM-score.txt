# LAB 13 / PSALM — vocal number. Candidate lab score; lyric text is a draft, not approved copy.
#
# LYRIC SYSTEM · psalmody, not song. One verse = two hemistichs separated by "/" (the caesura).
#   verse "first half / second half"     text for the singer and the public viewer
#   psalm init … tenor … med … fin …     the organ's tone formula:
#       init   intonation, sung once at the start of the first half
#       tenor  the reciting pitch: almost all syllables are chanted on it, in speech rhythm
#       med    mediant cadence closing the first half, then a half-breath
#       fin    final cadence closing the second half, then a full breath
#   verse 18 = one verse every 18 seconds; breath 3 = seconds of silence after it.
#   syll N re-attacks the tenor about N times per second (parlando); syll 0 holds it.
#   organum 0,7 doubles the tone at those intervals (fauxbourdon), one division per interval.
#   ison D2 holds a pedal note under each half and releases it in the breaths.
# The singer follows the organ's breathing, never a click. Text density is free: fewer or more
# syllables fit the same tenor.
#
# MIC FOLLOWER · `follow DIVISION SEMITONES …` sets the follower sends for the section, so the
# harmony that grows out of the voice changes with the form. The score never switches the
# follower on: enable MIC MIDI FOLLOWER in MIXER. Intervals are the matrix rows (0 2 3 4 5 7 10 12 21 26, ±).
