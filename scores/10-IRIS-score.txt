# LAB 10 / IRIS — iridescent chord number. Candidate lab score, not an approved release.
# One chord seen under a changing angle: the pitches stay, the light moves. The "angle" is
#   iris   which manual sounds which chord tone (rotates per hit)
#   ms     absolute attack length in milliseconds (30 = staccatissimo … 100)
#   hold   hits before the chord changes (5|3|7|2 = uneven arithmetic, never a metre)
#   morph  tones migrate to the next chord one by one instead of cutting
#   shadow a second, softer manual repeats each tone N ms later: the perceptual shadow
# Four GLINT sections are the only places where the laser answers (single points, Solo only).
