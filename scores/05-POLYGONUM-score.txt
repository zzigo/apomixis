# Apomixis 05 / POLYGONUM — Polygonum. ANTH · guided improvisation with the IMPRO pod, incremental.
# From lab 14 IMPRO (archived in archive/scores/labs/). Growth: the organist starts on Manual I only
# and ends with the hands (and feet) everywhere. Each section opens one more source: A I · B I II ·
# C I II III · D I II III IV · E–F all, pedal included. From F the operators change drastically
# every 15 s, with a profusion of random arpeggios (arpUR / arpDR / arpBR), and the registration
# changes every 7.5 s between neighbouring programs: reeds · mixtures · tremolos with Voix humaine ·
# plenum with tubas (55–58), at most ten programs so 05 keeps its ten (50–59).
# The organist plays Manual I (channel 1). The pod re-sends each note to other divisions:
#   tap DIVISION SEMITONES DELAY-MS   one echo: where, at which interval, how late
#   rep N every MS stretch F           repeat the whole chain N times, each pass later and slower
#   tail F                             echo length = held time × F (long tails → counterpoint)
#   decay P                            later passes thin out with probability P per pass
# This score only changes state and registration cue with the form; it plays no notes itself
# (apart from one pedal drone). IMPRO pod: ARM, SCORE checked, MIDI IN = the console.
# A tap can never target the source manual. The same lines work as states 1–9 in the pod.
id apomixis.polygonum
version 0.1.0-lab.1
title "POLYGONUM"
number polygonum
duration 330
seed 3141
audition-transpose 0

voice $SO = so range 36 84
voice $RE = re range 36 84
voice $PO = po range 36 84
voice $GO = go range 36 84
voice $PE = pe range 24 55
fertility $SO 0 end
fertility $RE 0 end
fertility $PO 0 end
fertility $GO 0 end
fertility $PE 0 end
harmonicity 0 "P8" "the player decides"
harmonicity 330 "P8" ""
